Story list row ideas

Each list below is a mockup of the Thread box's story list in hn_polarization.html, filled with sample stories. A click on a row writes what the click would do under the list instead of loading a thread or opening Hacker News. In every idea except 4, a click anywhere on the row other than the Hacker News link selects the story, and the title is plain text.

4. Current layout (baseline)

The title is the Hacker News link; the 12px detail text and the padding are the only areas that select the story.

    5. Short "discuss" link at the end of the row

    • The whole row, including the title, selects the story.
    • The link sits right-aligned in normal-size text with padding, so it is a deliberate target.
    • On a narrow screen the link wraps to the end of the detail line.

      6. Orange "HN" column at the right edge

      • A full-height cell at the row's right edge, in Hacker News orange, is the only link; it is the easiest link target to hit and the hardest to hit by accident.
      • The column lines up across rows, so the eye finds it without reading.
      • It costs about 3rem of row width.

        7. The comment count is the link

        • Hacker News itself uses the comment count as the link to the discussion, so the convention is familiar.
        • The count moves out of the small detail text into normal-size text so that it is easy to click.
        • The link has no fixed position; its horizontal place depends on the title's length.

          8. "Y" link at the start of the row

          • A square in a fixed left gutter opens Hacker News; everything to its right selects the story.
          • The link column lines up across rows and sits next to the title.
          • It sits where the pointer often rests while moving down the list, so a stray click opens a tab.

            9. Two-line rows

            • The title takes the first line in full, without truncation, followed by the "discuss" link; the detail moves to a second line at 13px.
            • Each row is taller, so each row is a bigger selection target, and the list shows fewer stories per screen.
            • This is the layout that hn_polarization.html already uses on a narrow screen.

              10. Link shown only on the hovered or highlighted row

              • Idea 5, with the link hidden on every row except the one under the pointer or highlighted with the arrow keys.
              • The list looks quieter, and the link appears where the pointer already is.
              • On a touch screen there is no hover, so the link appears only after a row is highlighted.

                11. Keyboard shortcut for the highlighted row

                • Arrow keys move the highlight; Enter selects the story and Ctrl+Enter opens the Hacker News discussion.
                • The highlighted row shows the shortcut as a hint. This idea combines with any of ideas 5 to 10.
